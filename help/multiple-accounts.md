One server can have several accounts. Each account is its own sign-in, with its own keys.

## Add a second account

1. Open [Accounts](/accounts/) and choose **Add account**.
2. Pick the server and give the account a name, like `work` or `personal`. It's saved as `gmail-work`.
3. Sign in, or paste its key.

## Keep them apart

Put each account in a different profile: `gmail-work` in **Work**, `gmail-personal` in **Personal**. An AI app connected to Work can't reach personal mail.

Tool names start with the account name (`gmail-work__send_email`), so when one profile holds both, the AI can tell them apart.

## Signing out

Signing out deletes that account's tokens from this computer. Other accounts on the same server keep theirs.

See also [Profiles](help:profiles).
