4 · FEATURES — bento, React Bits SpotlightCard (hover the cards)

What it does

One connection

Two tools, any number of servers.

Keys in your keychain

OAuth sign-in and refresh. The AI never sees a key.

Personal data masking Beta

Masks emails, phone numbers and IDs in tool results before a cloud model reads them. It doesn't touch what you type into the chat. Catches common patterns; it can miss things.

Profiles

One URL per purpose. An agent sees only its profile.

Approvals

Allow, ask or block, with one sentence saying why.

Tool pinning

A changed tool is quarantined until you review it.

Secret scanning

Keys in results or arguments are redacted.

Activity log

Encrypted. Values excluded. 30 days by default.

  • Tool pinning, secret scanning

  • Managed setup through MDM
  • Org policy packs
