# private-mcp-gateway

pMCPg, the Private MCP Gateway: one local endpoint between your AI clients and your MCP servers.

```bash
npx private-mcp-gateway serve
npm install -g private-mcp-gateway && pmcpg --help
```

npm installs the `pmcpg` binary for your platform from an `@baobabtech/pmcpg-<os>-<arch>` package.

Docs: https://github.com/baobab-tech/pMCPg
