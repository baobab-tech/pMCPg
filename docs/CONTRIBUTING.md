# Contributing

Issues and pull requests are welcome: [GitHub Issues](https://github.com/baobab-tech/pMCPg/issues).

- Report security problems privately, as [SECURITY.md](../SECURITY.md) describes.
- Read [design.md](design.md) before changing code. [concept.md](concept.md) says why pMCPg exists.
- New runtime dependencies need a written reason in the pull request.
- Before a pull request, run `bun run check` (biome and tsc) and `bun test`.
- The SVG diagrams in `docs/assets/` are generated: edit `docs/assets/src/` and run `python3 docs/assets/src/build_svgs.py`.
